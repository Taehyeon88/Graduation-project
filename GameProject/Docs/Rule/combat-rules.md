# 전투 규칙

## 1. 전투 판

- 4×4 그리드 격자판 위에서 전투가 진행된다.
- 좌표는 (x, y)로 표기한다.

## 2. 배치 구간

- 배치 구간은 `StageSO`에서 정해지며 스테이지마다 바뀔 수 있다. 아래는 기본 예시이다.

| 구분 | 좌표 |
|---|---|
| 플레이어 배치 구간 | (0,0), (0,1), (0,2), (0,3) |
| 적 배치 구간 | (3,0), (3,1), (3,2), (3,3) |

```
        x=0   x=1   x=2   x=3
y=0     [P]   [ ]   [ ]   [E]
y=1     [P]   [ ]   [ ]   [E]
y=2     [P]   [ ]   [ ]   [E]
y=3     [P]   [ ]   [ ]   [E]
```

## 3. 이동 범위

- 모든 영웅은 최대 적 배치 구간 이전까지만 이동이 가능하다.
- 모든 적은 최대 플레이어 배치 구간 이전까지만 이동이 가능하다.

### 3-1. 플레이어 영웅 수동 이동 (`MoveSystem`)

- 라운드(= 플레이어 턴 1회) 시작 시점의 영웅 위치를 **시작 위치**로 기록하고, 시작 위치를 중심으로 한 **3×3(주변 8칸, 대각선 포함)** 안에서만 이동할 수 있다.
- 이동 불가 칸: 그리드 밖, 유닛·장애물·중립지대가 있는 칸, **적 진영 배치 구간 칸**. 영웅 진영 배치 구간 칸은 빈 칸이면 이동할 수 있다(그 칸에 영웅이 서 있는 동안은 그 라인에 카드를 배치할 수 없다). 시작 위치 자체는 복귀 목적지라서 항상 허용한다(다른 유닛이 서 있으면 불가).
- 경로는 이동 가능한 칸 안에서만 8방향으로 잡는다. 3×3 밖으로 우회하지 않는다.
- AP: 시작 위치에서 다른 칸으로 처음 떠날 때 AP 1을 소모한다. 이후 3×3 안에서의 이동은 AP를 쓰지 않는다. 시작 위치로 돌아오면 소모했던 AP 1을 돌려받는다(소모한 적이 없으면 환급 없음).
- 시작 위치에 있는 영웅이 이동 모드에 들어가려면 AP가 1 이상이어야 한다. 이미 떠난 영웅은 AP가 0이어도 이동할 수 있다.
- **카드로 배치된 영웅은 배치된 라운드에는 이동할 수 없다.** 다음 라운드부터 이동할 수 있고 그때 배치 위치가 시작 위치가 된다. 전투 시작 전 초기 배치 영웅은 해당하지 않는다(1라운드부터 이동 가능).

## 4. 코어 공격

- 영웅, 적 모두 각 상대의 배치 구간 이전인 마지막까지 이동한 경우, 해당 라인 앞에 상대 유닛이 없을 경우, 상대 코어를 공격한다.

## 5. 카드와 AP

- 게임 시작 시, 뽑을 카드 더미에서 3장의 카드를 드로우한다.
- 카드를 사용했을 때만 버린 카드 더미로 이동한다.
- AP 1을 사용해서 카드 뽑기 버튼을 클릭할 때만, 카드 1장을 드로우하고 AP가 1 감소한다.
- 플레이어 턴 시작 시, 카드 드로우는 없다.
- 플레이어 턴 종료 시, 카드 버리기는 없다.
- 전투 시작 시, AP를 5 획득한다.
- 플레이어 턴 시작 시마다, AP를 3 획득한다.
- 최대 AP는 5이다. 최대치를 넘는 AP는 획득되지 않는다.
