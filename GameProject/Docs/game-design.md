# 턴/그리드 전략 로그라이크 — 게임 기획서

> 졸업 프로젝트 source of truth.
> 작성일: 2026-09-26

---

## 1. 개요

- **장르**: Isometric 뷰 턴/그리드 기반 전략, 로그라이크
- **레퍼런스**: Into the Breach, Master of Piece
- **목표**: 하나의 전투 스테이지 완성
- **플랫폼**: PC (Windows). 키보드 입력. **1920×1080 (16:9)** 기준

## 2. 타깃

전략 게이머, 그리드/턴 기반 전략, 전략 로그라이크 애호가

## 3. 핵심 재미

로지컬한 재미:
1. **밀려오는 적들의 압박** → 위기감 조성
2. **위기 탈출 및 웨이브 핵 파괴**를 위한 전략적 고민
3. **문제 해결의 쾌감** 제공

## 4. 게임 루프

```
시작
 ↓
게임 셋업
 ↓
전투 시작
 ↓
[메인 루프] 몬스터 턴 → 플레이어 턴 → 몬스터 턴 (반복)
```

## 5. 승리·패배

- **승리 조건**: 웨이브 핵 파괴, 웨이브 내 모든 몬스터 처치
- **패배 조건**: 모든 플레이어 유닛 사망

## 6. 명시적 비스코프

- 다중 스테이지, 다중 보스, 보스 페이즈
- 유닛 선택, 도전 과제, 로그라이크(런 기반 메타 진행)
- 세이브/로드 (한 판 단위로 끝)
- 인게임 옵션 메뉴 (음량·해상도 등)
- 터치 입력 (PC 키보드만)
- 다국어
